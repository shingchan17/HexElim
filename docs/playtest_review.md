# HexElim 0.1.5 试玩审查

## 启动

双击 `builds/HexElim.exe`，或者在 Godot 导入 `project.godot` 后按 F5。点击“开始游戏”或按空格。第一波在 2 秒后生成，之后每累计 1000 分缩短 0.1 秒，最短 1 秒，10000 分时达到下限。

## 操作

A 逆时针转一格，D 顺时针转一格；按住 S 加速，P/Esc 暂停，R 重开，M 开关音效，F11 / Alt+Enter 切换全屏。按钮也可用鼠标操作。

## 窗口与调试显示

默认窗口为 1600×900，棋盘和界面随窗口一起等比例缩放；非 16:9 窗口留边。全屏时占据屏幕内最大的 16:9 区域，退出全屏恢复原窗口大小、位置或最大化状态。全屏切换可以在开始、游玩、暂停和结束画面进行，不重置对局。

Godot 内嵌的游戏预览有独立的尺寸选项。项目启用的 **HexElim Debug Preview** 插件在加载与运行前，自动把实时预览切换为 **Stretch to Fit（适应窗口）**。更新前已打开的编辑器需重新打开项目以加载插件，然后按 F5 并最大化预览即可。插件随 Git 同步；单独改 `.godot/` 缓存会被运行中的编辑器覆盖，因此不再采用那种处理。

## 建议先检查这些体验

1. A/D 的方向是否符合直觉，60° 一步的转动是否跟手。
2. 六个固定方向的来块能否看清，旋转后落定到哪一边是否容易判断。
3. 三个及以上同色方块连接、跨相邻边同层连接时，消除是否符合预期。
4. 消除后向中心收拢及连锁是否易于理解，空中方块是否持续下落、没有整场停顿，闪光和声音是否清楚且不过强。
5. 连续四秒内消除时，倍率是否变为 ×2、×3……；超时后是否回到 ×1。
6. S 加速的手感、波次间的思考时间，以及每边十块带来的压力是否合适。
7. 暂停再继续、满边溢出结束、结束后重开是否正常。
8. 中文界面是否清晰，容量提示、分数和来块是否容易同时关注。
9. 最大化或全屏后棋盘是否放大，鼠标是否仍能准确点击；全屏与窗口往返是否保留对局。

## 首版需要你审查的规则选择

- 连接包含“相邻两边同层”，不包含只碰角点的斜向位置。
- 每波 1–6 块，方向不重复；四种颜色等概率。
- 一条边满十块不会立即结束，下一块到达却接不住时结束。
- 同批同时消除合并算一次事件，收拢引发的连锁另算一次事件。
- 转动动画内忽略额外 A/D，避免落点与画面错位。

反馈时可以直接描述“出现了什么、你期望怎样”，或指出想先调整哪项手感与规则。当前最佳分仅在本次启动中保存。

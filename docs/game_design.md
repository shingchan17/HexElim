# HexElim 0.1：当前设计与实现

## 核心循环

六个来向固定在屏幕中，玩家旋转中心六边形与已落定方块，决定新方块接到哪条边。方块落定后检查同色连通组，消除后向中心收拢，再检查新的连接。有限空间和连续消除窗口共同形成操作压力。

## 用户确定的规则

- 2D、六边形中心、A 逆时针、D 顺时针、S 加速下落。
- 六个固定来向，红黄绿蓝四色，随机数量和颜色。
- 至少三个同色相连时消除，每边最大容量 10 块。
- 本次分数为 `6 × 消除数量 × 连续消除次数`。
- 首次次数为 1，四秒内再次消除则次数加一并刷新四秒窗口；过期后下一次从 1 开始。
- 起始生成间隔三秒，每累计一千分减少 0.1 秒，最短一秒，20000 分后保持一秒。
- 分数上升时移动速度也提升；移动速度与生成间隔分别计算。

## 首版采用的具体方案

这些是为了交付可玩版本所采用的方案，供试玩审查与后续调整。

| 项目 | 0.1 实现 |
| --- | --- |
| 旋转 | 每次按下转 60°，动画 0.14 秒；本次动画完成前忽略额外转动 |
| 转动中来块 | 保持世界方向，等棋盘转正再落定 |
| S | 按住时移动速度乘 4，松开恢复；不加快生成时钟 |
| 波次数量 | 每波 1–6 块等概率，六个方向中不重复选择 |
| 颜色 | 每块独立从四色中等概率选择 |
| 相连 | 同边上下相邻层、相邻两边的同一层；支持第 5/0 边环绕；不含斜角接触 |
| 一次消除 | 同一批落定后检测出的全部合格连通组合并计分一次 |
| 连锁 | 同边向中心收拢后再检测，下一轮单独计分并增加连续次数 |
| 容量 | 一条边已有 10 块仍可游玩；新来块到达且无合法位置时结束 |
| 满边消除 | 容量以内的落定先参与消除，第 10 块可以触发消除自救 |
| 初始波次 | 开始后 3 秒出现第一波 |
| 难度档位 | `floor(总分 / 1000)`，在下一波安排时应用新的生成间隔 |
| 基础移动速度 | `min(180, 72 + 6 × 档位)` 像素/秒 |
| 消除表现 | 闪光、粒子、向中心收拢；每轮约 0.22 秒，空中块暂留 |
| 暂停 | 冻结生成、下落、旋转、连续计分窗口及棋盘特效 |
| 重开 | 清空棋盘、空中块、分数、连续次数、倒计时、朝向和特效 |
| 最佳分 | 本次程序启动中的最高分；重新启动程序时重置 |

## 棋盘数据与几何

棋盘包含六个由内向外排列的数组 `stacks[0..5]`，颜色以整数 0–3 表示。每个位置为 `(side, depth)`，深度 0–9。邻接图由四个候选邻居组成：同边深度加减一、左右相邻边的同层位置；不存在的格子不参与匹配。

`BoardModel.find_matches()` 使用连通组遍历，收集所有大小至少为 3 的同色组，且每块只计算一次。移除后按原顺序压实每条边，同时返回幸存块移动距离，供视图表现。

方向 0 指向屏幕正上方，其余方向按顺时针编号。Godot 屏幕坐标的正角度对应顺时针。来块映射到棋盘局部边：

```text
local_side = posmod(world_direction - orientation_steps, 6)
```

画面使用沿六边形每条边堆叠的梯形条块，邻接规则与条块的逻辑共享边对应。边界内共 60 个位置；某条边溢出即可结束，无需全部 60 格填满。

## 计分流程

1. 有效消除发生时，如果连续窗口有效，次数加一，否则设为一。
2. 本次得分为 `6 × 消除块数 × 次数`，加入总分。
3. 剩余窗口刷新为完整四秒，刷新不累加剩余秒数。
4. 消除并收拢，稍后检测下一轮连锁。

同样消除三块的连续三次事件分别得 18、36、54 分。依次消除三、四、五块时，分别得 18、48、90 分。窗口恰好到期时视为失效；少于三块的无效请求既不计分，也不增加次数或刷新窗口。

`ScoreManager` 可独立作为计分组件使用；主场景关闭它的独立帧回调，由游戏控制器统一推进模拟时钟，避免重复计时，并确保暂停时所有玩法时钟一起冻结。

## 场景与模块

```text
Main (Node2D, main.gd)
├── ScoreManager (Node)
├── BoardView (Node2D，位于 640,360)
├── HUD (CanvasLayer，运行时构建中文界面)
└── GameAudio (Node，合成音效)
```

`BoardModel` 与 `WaveGenerator` 是独立数据对象，控制器负责创建并协调它们。规则集中在 `GameRules` 资源中，视图读取棋盘状态并绘制，不反向用像素碰撞推断同色连接。

游戏有准备、游玩、暂停和结束四个状态。开始、继续和重开同时提供鼠标按钮与键盘入口。界面包含本局得分、连续次数与窗口、下一波倒计时、相对移动速度，以及对应六个世界方向的容量提示。

## 验证重点

- 旋转方向、0/5 边界与世界来向到局部边的映射。
- 两块不消除，三块起消除，跨边连接以及角点接触不算连接。
- 多组同时移除只增加一次连续次数；收拢形成的下一轮连锁继续计分。
- 基础分与连续窗口的刷新、过期、暂停和重开。
- 第十块消除自救、下一块溢出结束，且数组不会超过十块。
- 随机波次数量范围、方向不重复、四色合法和种子复现。
- 加速不改变生成时钟，分数提高会改变后续间隔和移动速度。
- 完整对局持续运行至自然结束，开始/暂停/结束界面的实际渲染和按钮操作。

## 后续审查方向

优先通过试玩调整旋转手感、移动速度、波次数量压力、跨边连接可读性及连续窗口。后续可加入持久化最高分、更丰富的声音与视觉表现。
